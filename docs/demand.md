## 已知限制

| 限制 | 说明 |
|------|------|
| 生成图保存 | 会话保存图片引用，服务商链接可能过期 |
| 无离线 PWA | 无 Service Worker |
| 不做鉴定 | 附图与生成图仅供临习参考，不作估价 |
| 系统提示 | 不交付完整成书；参考图生成仍可用 |
| 消息工具栏 | 投票等不持久化 |
| 外观偏好 | 保存在当前浏览器，换浏览器或清除站点数据后使用默认值 |
| 目录覆盖 | 内置精选字词、书家、法帖和诗词。馆藏字形覆盖少量示例，更多字可上传单字照片或使用字体示意 |
| 识字准确度 | 结果由部署的视觉模型返回，草书、拓片和模糊图片需人工核对 |
