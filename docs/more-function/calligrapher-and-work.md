# 书法家和作品

从输入框上方打开「书法家和作品」，在右侧切换「书法家」「代表作品」「收藏」。列表支持中文关键词，详情可打开馆藏目录。馆藏图像沿用站点已核实的本地授权素材。

## 书法家

`GET /api/study/people?q=…` 检索姓名、字号、朝代、别名和书体。人物卡显示时代、书体、简介、来源及相关作品入口。选择作品跳转到同一抽屉内的作品查找结果。

## 代表作品

`GET /api/study/works?q=…` 按作品标题、别名、书家、书体或年代查找。作品卡区分原作、摹本和拓片，含临摹建议及来源。目录链接可用于查看原图。支持展示的缩略图以图片说明注明局部和藏馆。

## 收藏功能

用户可收藏人物或作品，统一在「收藏」查看和移除。`GET /api/study/favorites` 返回当前账号的收藏，`PUT` 和 `DELETE /api/study/favorites/<kind>/<id>` 分别保存或移除。数据库复合约束保证重复操作幂等，所有查询使用服务端会话中的用户 ID。

表关系及扩充方式见[数据库设计](../database.md)。
