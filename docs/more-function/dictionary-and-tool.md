# 字典与工具

从输入框上方打开「字典与工具」，在右侧切换五个子工具。面板默认列出可查的示例，提交检索后显示匹配条目、读音、释义及来源。窄屏占满宽度。查词和打开资料不会清空对话草稿。

| 功能 | 查询与展示 | 实现 |
| --- | --- | --- |
| 书法字典 | 输入一个汉字。查看对应的书体、书家、出处与局部示例，可进入集字拼图。 | 条目和字形分别存入 `study_dictionary`、`study_glyphs`。馆藏局部以原图和裁切坐标保存，释义与馆藏示例分开显示。 |
| 汉语字典 | 用简体或繁体检索单字，查看拼音、部首、笔画、释义。 | `kind=character`，部首与笔画有独立字段。多音字可在读音和释义中分别说明。 |
| 汉语词典 | 用词语或短语检索，显示拼音、释义和用例。 | `kind=word`，优先匹配词头和别名，然后查找词头包含输入的条目。 |
| 篆刻印典 | 按术语或印名检索，查看白文、朱文等术语、印式及来源。 | `kind=seal`，术语说明与可授权展示的印蜕分开维护。首批为自编术语索引，来源链接可打开原始资料。 |
| 成语词典 | 用成语或常见别名检索，查看拼音、含义、出处和用例。 | `kind=idiom`，按词头和别名检索，典故出处和用法写入条目说明。 |

五个工具共用 `GET /api/study/dictionary/<kind>?q=…`。查询采用 Unicode 规范化，同时识别条目登记的简繁别名。接口最多返回 30 项。匹配为空时给出明确状态，现有种子只覆盖精选条目。追加资料时保留稳定 ID 和 HTTPS 来源，馆藏裁切同时核对作品、字形和图像许可。

数据库字段和导入方式见[数据库设计](../database.md)。
