# 练习与创作

「练习与创作」在输入框上方打开右侧面板。学习资料可带入拼图、章法排版或日历，结果由用户主动导出或复制。

| 功能 | 操作与实现 |
| --- | --- |
| 选帖学习 | 在 `GET /api/study/works` 接口按作品名、书家或书体检索。卡片显示作者、年代、版本、图像及临摹提示。可将该帖作为练习内容加入日历。 |
| 集字拼图 | 输入待组字文本，按字从书法字典取得可用馆藏字形。每格可选对应样本，也可上传单字图片替换。浏览器用 Canvas 按格导出 PNG。没有图像的格使用字体示意，样本出处列在预览下方。 |
| 繁简转换 | 选择简转繁或繁转简，经 `POST /api/study/text/convert` 调用 OpenCC 的词组规则，保留标点和换行。输出可复制或带入章法排版。异体和地区用字仍需人工核对。 |
| 看图识字 | 上传 JPEG、PNG 或 WebP，由 `POST /api/study/ocr` 使用部署的视觉模型识别，按阅读顺序返回可编辑文本。无法辨认的字提示用 `□`，结果可带入排版。图片仅在本次请求中交给模型服务商。 |
| 字数统计 | `POST /api/study/text/count` 返回 Unicode 码位数、非空白码位数、汉字数和行数。有内容时，末尾换行后的空行计入行数。 |
| 唐诗宋词 | `GET /api/study/poems` 按题名、作者或正文检索，可选择唐诗或宋词。显示署名、全文和底本链接，正文可一键带入排版。 |
| 章法排版 | 输入正文，选择横排或竖排及每行、每列字数，调整纸张与落款。Canvas 按行或按列绘制，竖排从右向左。预览和 PNG 共用绘制逻辑。 |
| 书法日历 | 按月查看个人练习计划。选择一天添加练习，可带入法帖、编辑计划、标记完成或移除。以 `YYYY-MM-DD` 保存个人日历日期，每人每天一条。 |

拼图照片、转换结果、识别结果和排版稿在当前页面中使用。日历任务随账号保存，跨设备恢复。书法字形与诗词来源见[数据库设计](../database.md)。
